# Documento B23: Validación del sensor de peso

**ID de fuente:** B23
**Emisor:** Metrología
**Fecha:** 2026-11-18 19:47
**Tipo:** dictamen
**Estado:** servidor

## Contenido

Un control previo a la exposición dio 620±2 g para K17-O y 580±2 g para K17-R. Se verificó el sensor después del incidente; desvío máximo 3 g. Una variación de 40 g es compatible con reemplazar uno por otro, no con fluctuación de temperatura ni reinicio electrónico.

El sensor de pedestal no informa si hubo intención dolosa. La conclusión física «la carga cambió a las 18:27» tiene alta confianza; la atribución personal requiere otras fuentes.
